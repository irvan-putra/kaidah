# Before you publish

- [ ] Does it contain only your own work, or work you have permission to share?
- [ ] For AI-assisted work, have you distinguished substantive human contributions from machine-generated material without publishing private prompts or chats?
- [ ] For reused code and dependencies, have you checked the actual license and retained required notices? AI-generated does not mean third-party rights are absent.
- [ ] If others contributed, did you ask about publishing and attribution separately?
- [ ] Is anyone identifiable from names, details or phrasing?
- [ ] No passwords, keys, tokens, private links or account identifiers?
- [ ] No personal, device or location details, and no private chat text?
- [ ] Scanned the full history, not only the current files?
- [ ] Checked access from a signed-out view?
- [ ] Claims match what was actually verified? Open items marked as open?
- [ ] Commit attribution matches what the owner explicitly authorized, and you have the commit link?
